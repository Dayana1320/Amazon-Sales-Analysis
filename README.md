# Amazon Sales Performance Analysis Using Excel

## Project Overview

This project focuses on analyzing **Amazon sales data using Microsoft Excel** to understand product performance, customer behavior, sales trends, payment methods, and order status.

The project uses Excel for **data cleaning, preprocessing, PivotTable analysis, data visualization, and interactive dashboard creation**.

---

## Problem Statement

Managing large amounts of e-commerce sales data can make it difficult to identify top-performing products, understand customer behavior, track sales performance, and monitor order status.

This project addresses this challenge by cleaning and analyzing Amazon sales data in Excel and creating an interactive dashboard to generate meaningful business insights.

---

## Project Objectives

* Understand and prepare the sales dataset
* Clean and preprocess the data
* Analyze product and category performance
* Analyze customer locations and purchasing behavior
* Analyze payment methods
* Analyze order status
* Identify top customers
* Create an interactive Excel dashboard
* Generate useful business insights

---

## Dataset Description

The dataset contains Amazon order-level sales information.

| Column              | Description             |
| ------------------- | ----------------------- |
| `Order ID`          | Unique order identifier |
| `Date`              | Order date              |
| `Product Name`      | Name of the product     |
| `Category`          | Product category        |
| `Price`             | Product price           |
| `Quantity`          | Quantity ordered        |
| `Total Sales`       | Total sales value       |
| `Customer Name`     | Customer name           |
| `Customer Location` | Customer location       |
| `Payment Method`    | Payment method used     |
| `Order Status`      | Current order status    |

## Data Cleaning

The following data cleaning techniques were applied:

* Removed duplicate records
* Standardized date formats
* Formatted numerical values
* Cleaned text using `TRIM()` and `PROPER()`
* Checked missing values
* Validated Total Sales values
